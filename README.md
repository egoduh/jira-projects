# jira-projects

Локальный веб-сайт со списком проектов из **Jira Server/DC 8.13.20**
(`GET /rest/api/2/project`).

Один файл `server.py`, только стандартная библиотека Python — ни `pip`, ни зависимостей.
Сервер сам ходит в Jira и отдаёт готовую страницу: это обходит CORS и не светит токен
в браузере.

Аутентификация — токен **Kantega SSO Enterprise** (Bearer). Kantega выдаёт персональные
токены поверх Jira 8.13, у которой нет нативных PAT (они появились только в Jira 8.14).

## Запуск

Нужен только `python3` (обычно уже стоит). Секреты берутся из файла `.env`
рядом со скриптом (server.py читает его сам) либо из переменных окружения.

```bash
cp .env.example .env      # впиши JIRA_BASE_URL и JIRA_TOKEN
python3 server.py         # открой в браузере http://localhost:8000
```

### В VSCode

- **Самый простой способ (без debugpy):** Terminal → New Terminal → `python3 server.py`.
  Или Terminal → Run Task → «Запустить сайт».
- **По F5** — требует установленного `debugpy` (движок отладки). Если VSCode просит его
  поставить, а установка блокируется (`externally-managed`/прокси) — просто используй
  запуск через терминал выше, отладчик для этого сайта не нужен.

На странице: таблица Ключ / Название / Лид / Тип, живой фильтр по ключу и названию,
сортировка по клику на заголовок, ссылка на каждый проект, кнопка «Обновить».

Режим Basic (если токен Kantega работает как пароль): `JIRA_AUTH_MODE=basic` + `JIRA_USERNAME=<логин>`.
Корп. self-signed CA: `JIRA_INSECURE=1`.

## Переменные окружения

| Переменная       | По умолчанию | Назначение                                   |
|------------------|--------------|----------------------------------------------|
| `JIRA_BASE_URL`  | —            | URL инстанса без `/rest/...`                 |
| `JIRA_TOKEN`     | —            | Токен Kantega (bearer) или пароль (basic)    |
| `JIRA_AUTH_MODE` | `bearer`     | `bearer` или `basic`                         |
| `JIRA_USERNAME`  | —            | Только для `basic`                           |
| `JIRA_INSECURE`  | —            | `1` — не проверять TLS                        |
| `JIRA_TIMEOUT`   | `30`         | Таймаут, сек                                 |
| `PORT`           | `8000`       | Порт локального сайта                        |

Секреты через окружение, в git не попадают.
